截图核对结论（与 SVG/需求表冲突时以截图为准）：

1. 底部工具栏确为 **15 个工具 + 3 条分隔线**，顺序与 SVG1 一致，槽距 44、左右内边距 15。
2. 右侧属性栏比 SVG 多出分组标题：**尺寸 / 背景 / 添加布局**（合并模式：尺寸 / 外边框 / 背景 / 文件格式）。
3. 外边框 / 间距 / 圆角不再是“左侧标签 + 右侧 60×28 深色框”，而是 **左标签 + 右侧数值 + 单位 PX** 同一行，
   下方细滑条（白色圆形拇指，无绿色）。
4. 尺寸行是 **两枚 86×28 描边输入框**（内含「高 / 宽」+ 数值 + PX），不是纯 TextBox。
5. 背景是 **7 个色块**：白 / 黑 / 绿 / 蓝 / 黄 / 自定义（彩色）/ 图片背景，不是 SVG 的 6 个。
6. 添加布局为 3 张 **59×59** 卡片，预览为 **1 格 / 上下 2 格 / 2×2**。
7. 顶部胶囊四个图标按截图识别为 **锁定 / 解锁 / 剪刀（分割）/ 四向展开（适应画布）**，
   与 SVG 的“左旋 / 右旋 / 居中”不同，以截图为准。
8. **画布底色冲突**：截图制作拼图的空态工作区是 `#171717`，与“默认画布区域整体白色”不一致。
   本规格的处理：工作区外壳按截图 `#171717`；**拼图画板纸与导出底默认 `#FFFFFF`**（有布局后可见）。
   若用户要求整个 900×640 区域都白，请指出。

### 1.6 必须新增或扩展的部分（现有控件不支持）

1. `Ling::Slider` 需要 4px 细轨 / 2px 圆角 / 白色圆形拇指 / 自定义激活色；缺则扩展。
2. `Ling::TextBox` 需要 28px 高、无边框、透明底、文字右对齐（属性行）；缺则扩展。
3. 组合输入框（「高/宽/PX」「行/列」）需在 `WinImageEdit` 内新增 `buildFieldRow()` 组合函数（不新增控件类）。
4. 第 7 个“自定义颜色”色块需要取色入口；项目若无现成取色器，复用系统 `ChooseColor` 或已有颜色控件。
5. `SettingUi::Popup` 需支持深色配色参数（把现有 `WinImageEdit` 自建深色版抽成参数，不改全局主题）。
6. 标注类工具（矩形/箭头/线段/马克笔/文字/数字/马赛克/模糊/橡皮擦/识别文字/贴图）本轮只恢复按钮与选中态，
   画布绘制不在本轮范围（需求存档未定义这些工具的拼图行为）。
