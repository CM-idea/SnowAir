# 贴图右键菜单 + 缩略图 + 缩放交互（免费版）规划

> 目标工程：免费版 `SnowAir/Native`（Win32 + Direct2D + Ling 框架）
> 状态：**需求已确认**（2026-10-12），等待开工指令后进入编码

---

## 0. 目标

给桌面贴图（`WinPin`）补上三块能力，行为与既有实现对齐：

1. **右键菜单**：在贴图上点右键弹出功能菜单（复制 / 保存 / 编辑 / 变换 / 缩略 / 专注 / 置顶 / 边框 / 不透明度 / 缩放模式 / 识别文字 / 关闭）。
2. **双击 → 缩略图**：双击贴图收成一个以光标为中心的小方块；再次双击还原。
3. **缩放交互**：鼠标悬停在贴图上，**滚轮直接放大/缩小**；**拖动贴图边缘等比缩放**。

**复制不再关闭贴图**（用户确认）。

## 1. 现状（免费版）

| 能力 | 现状 |
|---|---|
| 右键 | 非编辑态**无响应**；编辑态是"切换工具条显隐"（[WinPin.cpp](../../Src/Win/WinPin.cpp) `annotRightClick`） |
| 双击 | `annotDoubleClick` 直接**复制到剪贴板并关闭贴图** |
| 缩放 | 只有 **Ctrl+滚轮**才缩放（[WinPin.cpp](../../Src/Win/WinPin.cpp) `onMouseWheel` → `applyScale`）；**没有拖边缩放**（鼠标不在边缘变色、不能拖边） |
| 设置 | 已有 `pinDoubleClickAction`（`0=切换缩略图 / 1=关闭贴图`，默认 0）、`pinZoomAtCursor`（默认开），但 `WinPin` **没读取**（`Setting.cpp`） |
| 语言 | `pin.*` 命名空间已有 `cancelEdit / confirmEdit / showBorder`；设置页键 `pinDoubleThumb / pinDoubleClose` 已存在 |
| 菜单基建 | 托盘已有一套**自绘圆角菜单**（`Tray.cpp` 的 `TrayMenuWindow` + `MenuPalette`），可抽取复用 |
| 缺失能力 | 旋转/翻转底图、内容不透明度、裁剪放大、专注模式、置顶开关、贴图 OCR —— 免费版**均无**，需新建 |

**关键结论**：设置项与部分文案已埋好，缺的是 `WinPin` 的交互与菜单本体 + 若干新能力。

## 2. 需求总览

### 2.1 右键菜单项（按既有习惯排序）

```
──────────────
编辑贴图
变换                ▸  逆时针 90° / 顺时针 90° / 垂直翻转 / 水平翻转
──────────────
缩略模式            ← 可勾选
专注模式            ← 可勾选（隐藏其他贴图）
窗口置顶            ← 可勾选
显示边框            ← 可勾选
──────────────
不透明度            ▸  25% / 50% / 75% / 100%
缩放模式            ▸  直接放大 / 裁剪放大
──────────────
关闭贴图
```

> 说明：菜单里**没有**"锁定"项（锁定是悬停按钮），本版同样不加。

### 2.2 双击行为

读 `Setting::getPinDoubleClickAction()`：

- `0`（默认）→ 进入/退出**缩略图**
- `1` → **关闭贴图**

### 2.3 缩放交互

- **滚轮缩放**：鼠标悬停在贴图上，滚轮**直接**放大/缩小（不再需要按住 Ctrl）；**以鼠标所在一侧（边/角）为固定基准、画面朝反向伸缩**（从右边进 → 以右边为基准），不走"虚空画布"那套。
- **拖边缩放**：鼠标移到贴图**边缘 7*dpi 区域**，光标变成对应方向箭头，按住拖动**等比缩放**。

## 3. 交互细则

### 3.1 右键菜单

**触发条件**
- 贴图窗口、**非编辑态**、**未锁定**、右键按下 → 光标处弹出。
- 锁定态：不弹。
- 编辑态：保持现状（右键=退出/取消当前步），**不弹菜单**。

**样式**
- **沿用托盘右键菜单的外观**：自绘圆角、主题色、行高 28、悬停高亮、上下留白、点菜单外关闭、不抢前台（直接复用托盘菜单那套观感/配色）。
- 含**勾选项**（左侧对勾）与**子菜单**（右侧箭头，悬停展开）。

**菜单项行为**

| 项 | 行为 | 复用/新增 |
|---|---|---|
| 复制到剪贴板 | 合成当前画面（含标注）→ 剪贴板；**不关闭** | `getAnnotPixels` + `Util::saveToClipboard` |
| 以文件复制 | 按输出设置存文件 → 路径写入剪贴板（CF_HDROP） | `Util::buildSavePath` + `saveToFile` + `addFileToClipboard` |
| 保存为文件… | 弹另存为对话框 | `Util::getSaveFilePath` + `saveToFile` |
| 显示识别结果 | 勾选：跑截图同款 OCR 并在图上叠识别框、文本进剪贴板；取消：收起 | 复用 `ToolOcr`（见 3.3.6） |
| 编辑贴图 | 进入编辑态（等价悬停"编辑"按钮） | `setEditing(true)` |
| 变换 ▸ | 见 3.3.2 | 新增 |
| 缩略模式 | 勾选：进缩略图；取消：还原 | 见 3.2 |
| 专注模式 | 勾选：隐藏其他贴图；取消：恢复 | 新增（`winPins` 遍历） |
| 窗口置顶 | 勾选：置顶；取消：取消置顶 | 新增（`SetWindowPos`） |
| 显示边框 | 切换边框显隐 | `toggleBorderVisible` |
| 不透明度 ▸ | 25/50/75/100%；**持久化**、**悬停显示原图**、编辑工具栏同名按钮 | 见 3.3.8 |
| 缩放模式 ▸ | 直接放大 / 裁剪放大 | 新增（见 3.3.5） |
| 关闭贴图 | 关闭该贴图 | `close()` |

**边界**
- 缩略图态下仍可弹菜单，「缩略模式」呈勾选态。
- 专注模式被勾选的那张关闭时，需把此前被它隐藏的贴图**恢复显示**（避免"永久消失"）。
- 多屏/DPI：菜单按光标所在显示器定位与钳制。

### 3.2 双击 → 缩略图

**进入缩略图**
- 目标窗口 = 以光标为中心、边长 `50 * dpi` 的正方形，clamp 到屏幕工作区。
- 记录进入前的**窗口几何 + scale**，退出时原样恢复（恢复也 clamp）。
- 缩略图态：
  - 隐藏悬停三按钮（锁定/编辑/关闭）；
  - 禁止拖动整窗、禁止滚轮缩放、禁止拖边缩放；
  - 光标保持普通箭头；
  - 画面用 **center-crop**（等比覆盖填满方块，不压扁）。
- **本期不做**：进入/退出缩略图的几何缓动动画（**最后再补**）。
- **悬停显示原图**：贴图（含缩略图态）鼠标悬停时按 **100% 不透明度**显示原图，移开恢复设定不透明度。

**退出缩略图**
- 再次双击，或菜单「缩略模式」取消勾选 → 恢复进入前几何与 scale。

**联动**
- 缩略图态下点「编辑贴图」：先退出缩略图恢复原尺寸，再进入编辑。

### 3.3 各菜单项细则

#### 3.3.1 复制 / 以文件复制 / 保存
- 全部基于**当前合成画面**（`getAnnotPixels`，含矢量标注）。
- 「以文件复制」「保存为文件」走输出设置的文件名模板（与截图输出一致）。
- 复制后**不关闭**贴图。

#### 3.3.2 变换（旋转/翻转）
- 与既有实现一致：**先把标注烘焙进底图**（`getAnnotPixels` 合成新位图）→ 清空矢量标注 → 对位图做变换。
- 逆时针/顺时针 90°：`w/h` 互换，窗口以原中心重排并 clamp 到屏幕。
- 水平/垂直翻转：尺寸不变，只镜像像素。
- 变换后 `scale` 重置为 1:1。
- 变换是不可逆的一次性操作（连按两次旋转回到原样）。

#### 3.3.3 缩略模式
- 见 3.2。

#### 3.3.4 专注模式 / 窗口置顶 / 显示边框
- 专注：`winPins` 里除自己外全部 `hide()`，打标记；取消时按标记 `show()`；专注贴图关闭时自动恢复其余。
- 置顶：`SetWindowPos(HWND_TOPMOST / HWND_NOTOPMOST)`；默认勾选（贴图本就 topmost）。取消置顶后新贴图仍默认置顶，此开关只影响当前这张。
- 边框：直接调 `toggleBorderVisible()`。

#### 3.3.5 缩放模式（直接放大 / 裁剪放大）
- **直接放大**（默认）：现状——窗口跟着变大（`applyScale`）。
- **裁剪放大**：窗口尺寸不变，改**取景**（放大镜效果）：
  - 新增 `m_cropScale`（≥1）、`m_cropCenter`（图内中心）；
  - 该模式下滚轮改 `m_cropScale`（放大镜倍率），不按光标缩放；
  - 绘制时按 `cropSourceRect` 取源矩形铺满窗口（等比 cover）。
- 两项互斥、可勾选显示当前模式。

#### 3.3.6 识别文字（显示识别结果）
- **与截图的"识别文字"完全一致**：复用截图那套 OCR 结果面板（`ToolOcr`）。
- 做法（方案 A）：把 `ToolOcr` 的宿主依赖从 `WinCap*` 泛化成最小接口（需要 dpi / 宿主 hwnd / 覆盖矩形 / 键盘转发），**贴图与截图共用同一套结果面板**。
- 点击后在贴图上叠识别框（可选中文本），识别文本写入剪贴板；菜单项勾选态表示覆盖层开/关。

#### 3.3.7 关闭贴图
- 复用现有 `close()` 路径（含"最后一个贴图关闭后 auto-quit / 检查更新"逻辑）。

#### 3.3.8 不透明度（持久化 + 悬停原图 + 工具栏入口）
- 只作用**画面层**（含标注），**悬停三按钮不变淡**。
- 菜单「不透明度 ▸」：25% / 50% / 75% / 100%。
- **持久化**：设置的百分比存进 `Setting`（如 `pinOpacity`），**新建贴图沿用**；也可作为"上次使用值"恢复。
- **悬停显示原图**：鼠标停悬在贴图上时按 **100%** 显示，移开恢复设定百分比。
- **编辑工具栏入口**：在贴图**编辑工具栏**「显示边框」按钮**右边**新增一个「透明度」工具（`border` 之后插入 `opacity` 槽）；点开一个**滑条弹层**（复用 `PropSlider`，承载在右键菜单那套自绘弹层里）调百分比，与菜单/设置同步。

### 3.4 缩放交互细则

#### 3.4.1 滚轮缩放（悬停即生效）
- **鼠标悬停在贴图上滚轮** → 直接缩放，**无需 Ctrl**（Ctrl+滚轮保留为同一行为）。
- **实现方式**：**不走"虚空画布"那套**，直接改窗口几何（`applyScale` 现成能力），简洁够用。
- 缩放系数：`factor = 1.1 ^ (滚轮格数)`（一格 ≈ 1.1×，连续滚累积；触摸板小格按比例折算）。
- **锚点 = 鼠标所在/进入的那一侧（边或角），画面朝反向伸缩**（不是"以光标为中心"）：
  - 例：鼠标**从右边**进入贴图 → **以右边为固定基准**（右边缘不动，画面向左放大/缩小）；
  - 左 / 上 / 下同理；从**角**方向进入 → 以该**角**为固定基准；
  - 光标落在**正中区域** → 以窗口**中心**为基准（退化情形）。
  - 判据：取光标在窗口内**最近的那条边（或角）**作为固定基准（边取中点、角取角点）。
  - 效果：光标附近（贴图那一侧）稳定不动，画面朝反方向伸缩 —— 不闪烁、自然。
- 范围：**缩放上限 1000%（10×）**；下限 10%（沿用现有下限）；到极限时滚轮无动作。
- 现有 `Ctrl+滚轮` 路径保留不变。
- **生效条件**：贴图**非编辑态、未锁定、非缩略图态**才缩放。
  - 编辑态：滚轮仍归标注（选中形状时调形状），沿用现状，避免与标注冲突；
  - 缩略图态 / 锁定态：滚轮无效。
- **`pinZoomAtCursor` 设置**：新锚点规则（以鼠标所在边/角为基准）下，"以光标为中心"语义不再适用 → **该设置对贴图滚轮不再生效（忽略）**。

#### 3.4.2 拖边缩放
- **命中区**：贴图**四边/四角**内缩 `7 * dpi` 的区域。
- **光标**：按命中的边位切换为水平/垂直/两种斜向缩放光标（`IDC_SIZEWE / SIZENS / SIZENWSE / SIZENESW`）；未命中仍是移动光标。
- **拖动**：按住某条边/角 → **等比缩放**：
  - 锚点 = **对边/对角**（拖左边 → 右边固定；拖角 → 对角固定）；
  - 水平边按宽度算比例、只有上下边时按高度算；比例钳制到同一缩放范围。
- **生效条件**：**非编辑态、未锁定、非缩略图态**（编辑态边缘留给标注交互）。
- 与「缩放模式」的关系：拖边改的是**窗口几何**（等比）；「直接放大」下等价改 `scale`；「裁剪放大」下窗口尺寸即取景框（取景倍率 `cropScale` 不变）。
- 缩放结束后，悬停的缩放提示（`scaleTip`）照常显示。

## 7. 决策点（已确认）

1. **菜单外观**：**用托盘右键菜单的外观**（自绘，复用托盘菜单配色/圆角）。
2. **缩略图动效**：本期**不做**进入/退出的几何缓动动画 → **最后再补**。
3. **识别文字**：**和截图识别完全一致**，复用截图那套 OCR 面板（泛化 `ToolOcr` 宿主依赖）。
4. **Ctrl+C / 复制**：保留，且**复制不关闭**贴图。
5. **不透明度**：**持久化**（写入 `Setting`，新贴图沿用）。
6. **悬停显示原图**：鼠标停悬时按 100% 显示，移开恢复设定不透明度。
7. **编辑工具栏透明度入口**：「显示边框」**右边**加一个「透明度」工具（点开滑条弹层）。
8. **拖边缩放**：**只等比**。
9. **缩放上限**：**1000%**。
10. **滚轮锚点规则**：以鼠标所在/进入的那一侧（边或角）为**固定基准**、画面朝反向伸缩；正中以中心为基准；`pinZoomAtCursor` 对本滚轮缩放**忽略**。
11. **编辑态滚轮**：保持现状（编辑态滚轮归标注，不缩放贴图）。
12. **不透明度作用域**：只作用画面层，悬停三按钮不变淡。
