# 图片编辑功能需求存档

> 范围：本文件只归档需求与实现落点，不含代码改动。
> 依据：用户确认稿、两份界面布局 SVG、现有设置中心与截图标注代码。
> 状态：需求已确认；少量歧义与冲突处理见第 9 节。

---

## 1. 功能总览

新增「图片编辑」功能，采用独立窗口，分为两个并列模式：

| 模式 | 目标 | 输出 |
|---|---|---|
| 制作拼图 | 把多张图片排入布局格子，支持分割、缩放、背景与边距设置 | 图片 |
| 合并文档 | 把多张图片按顺序合成为文档 | PDF / PPTX |

两个模式共用同一套窗口外壳、右侧属性栏、底部操作区与图标字库，仅属性项与画布内容不同。界面风格沿用设置中心：同一套主题色、圆角、控件高度与下拉/浮层机制。

窗口默认尺寸 1159×807，允许缩放。两个模式互不干扰；切换模式时若当前模式已有内容，先提示是否丢弃，确认后清空再切换。

### 1.1 功能入口

功能提供两个入口，打开同一独立窗口：

| 入口 | 位置 | 状态 |
|---|---|---|
| 全局热键设置 | 「其他」分组新增「制作拼图」，排在「开关设置」之后；默认不绑定，由用户录制 | 待实现 |
| 托盘右键菜单 | 新增条目，放在「快捷翻译」下面，与「快捷翻译」同组 | 功能完成后再加入 |

实现落点：

- 热键分组定义在 `Native/Src/Win/WinSettingHotkeys.cpp` 的 `groups` 数组「其他」组内，当前顺序为「开关设置、打开截图目录、开关历史记录、开关贴图」；新条目插在「开关设置」之后。
- 热键 id 需登记到 `Native/Src/Setting.cpp` 的 `kHotkeys` 表与 `Setting::onHotKey` 派发分支；默认键位为空，录制时复用同页的撞键检测与覆盖确认。
- 托盘菜单行定义在 `Native/Src/Tray.cpp` 的 `kMenuRows` 数组，命令枚举为 `MenuCmd`，点击派发在 `runTrayCommand`；条目插在 `kCmdQuickTranslate` 之后、原分隔行之前。功能未完成前不加入该行。
- 两个入口最终调用同一个初始化函数，打开独立窗口并默认进入「制作拼图」。

## 3. 制作拼图

### 3.1 画布与格子

- 画布是拼图的最终输出范围，可在其中建立多个格子。
- 格子是图片的承载单元，每个格子承载一张图片。
- 格子尺寸、位置由布局决定；分割工具可在已有格子上继续切分。
- 选中格子时，右侧尺寸区显示该格子尺寸；未选中格子时显示画布尺寸。

### 3.2 分割工具

- 必须先选中一个格子才能使用分割。
- 分割支持任意角度；按住 Shift 时按 8 向吸附（0°、45°、90°、135°、180°、225°、270°、315°）。
- 分割后图片内容被裁开，显示为两个格子；两个格子作为一个选择单元，选中只按一个格子计算，避免非矩形区域造成错位与留空。
- 再次选中格子并选择分割工具，可对分割结果进行二次调整。
- 双击已放入的图片可重新选择图片，等同于重新上传。

### 3.3 布局

- 工具栏「布局」位于「分割」右侧。
- 单击右侧属性栏中的预设布局卡片即可应用；当前选中卡片以描边高亮。
- 也可在「添加布局」给定行数、列数，再在画布上拖出对应格子。
- 行 / 列是拖出格子的数量上限，不是自动等分网格。
- 拖出格子时按住 Shift 约束比例，等比缩放。

### 3.4 格子填充图片

- 单击格子后选择一张图片放入；也可从资源管理器直接拖入格子。
- 默认按原比例填满格子，超出部分裁切。
- 按住 Shift 拖入或调整时允许不等比拉伸。
- 双击图片可重新选择图片。
- 一个格子只承载一张图片；再次放入新图片时替换旧图。

### 3.5 画布缩放

- 未选中任何工具时，滚轮缩放画布。
- 以鼠标位置为缩放中心。
- 缩放比例在画布左上角临时显示。
- 缩放范围 20%–1000%。

### 3.6 尺寸显示与单位切换

- 未选中格子：画布右上角显示画布尺寸。
- 选中格子：显示该格子尺寸。
- 单击「PX」在像素与百分比之间切换。
- 百分比相对画布尺寸计算。

### 3.7 背景

- 支持设置背景颜色：预设色板单选，另提供自定义颜色入口。
- 支持选择一张图片作为背景。
- 图片背景默认铺满并裁剪。
- 背景作用于画布空白区域，导出时随画布一并输出。

### 3.8 底部素材区与其他属性

- 底部素材条是已放入图片的列表，绿色描边表示当前选中的图片。
- 按确认稿移除「+」添加槽；新增图片通过格子单击或资源管理器拖入。
- 外边框、间距、圆角均提供数值框与滑条，作用于画布内的格子与内容。

## 4. 合并文档

### 4.1 工作区与导入

- 可把多张图片拖入工作区，也需提供文件选择入口作为补充。
- 图片以 140×160 卡片排列，每行 5 张，卡片下方显示文件名。

### 4.2 顺序调整

- 通过拖拽卡片修改图片顺序，顺序决定文档页面顺序。
- 拖拽过程需有插入位置提示；具体视觉反馈未明确。

### 4.3 文档属性

- 外边框：页面四周留白。
- 背景色：页面底色，预设色板 + 自定义颜色 + 图片背景。
- 文件格式：下拉选择 `.PDF` 或 `.PPTX`；由本程序直接生成文件，不调用本机 PowerPoint/WPS。

### 4.4 尺寸与单位

- 与拼图模式一致的「高 / 宽」双输入与互换按钮。
- 尺寸为 0 时按原图尺寸；指定尺寸时所有页面统一为指定尺寸。

## 5. 状态与交互约定

### 5.1 模式切换

- 「制作拼图」与「合并文档」互不干扰。
- 切换前若当前模式已有内容，弹出确认提示；确认丢弃后清空内容并切换。

### 5.2 工具与选择

- 工具选中态与「未选中任何工具」互斥，工具栏同一时刻只高亮一个工具。
- 格子选中与工具选中可以并存。
- 单击图片或格子后显示顶部悬浮胶囊；未选中时不显示。

### 5.3 鼠标与修饰键

| 场景 | 行为 |
|---|---|
| 无工具时滚轮 | 以鼠标位置为中心缩放画布 |
| 分割时按住 Shift | 角度 8 向吸附 |
| 拖出格子时按住 Shift | 约束比例，等比缩放 |
| 填图/调整时按住 Shift | 允许不等比拉伸 |
| 双击图片 | 重新选择图片 |
| 拖入图片 | 光标所在格子为目标格子 |

### 5.4 撤销与重做

- 拼图画布支持撤销、重做，入口位于底部工具栏右侧。

## 6. 导出规则

### 6.1 尺寸为 0

- 按实际图片尺寸输出。
- 合并文档中每张图片保持各自原图尺寸，不做统一页面尺寸。
- 不额外放大。

### 6.2 指定尺寸

- 所有页面统一为指定尺寸（如 1920×1080）。
- 图片按最宽、最高等比缩放到指定尺寸以内，不拉伸、不变形。
- 图片在页面内居中，剩余区域由背景色或背景图填充。

### 6.3 制作拼图导出

- 输出画布范围，包含背景、格子内图片、外边框、间距与圆角效果。
- 输出格式与截图保存格式一致：PNG、JPEG、WebP、BMP。

### 6.4 合并文档导出

- 按图片顺序逐页生成 PDF 或 PPTX。
- PDF 为必做格式；PPTX 由本程序直接生成，若实现成本过高可先只支持 PDF。
- 每张图片一页，不允许一页放多张图片。

### 6.5 属性在导出中的处理

- 背景色/背景图进入最终输出。
- 合并文档仅保留外边框，作为页面四周留白；不提供间距与圆角。
- 拼图的外边框、间距、圆角作用于画布输出。
- 两个模式的属性互不混用。

### 6.6 保存入口与命名

- 通过「保存」打开另存为对话框，默认目录为桌面。
- 拼图默认导出图片；合并文档按所选格式导出 PDF/PPTX。
- 命名沿用截图命名规则，用户在保存时可自定义文件名。

### 7.2 设置中心 UI 组织方式

现有设置中心的组织方式可直接沿用：

- 窗口：`WinBase` 派生，`body` 为横向容器。
- 卡片内滚动：`ScrollerBox`；需要固定底栏的页面直接把页面挂到卡片视口节点。
- 子页：每页为 `Ling::Node` 派生类。
- 主题：`SettingTheme` 语义色在页面构建前统一应用，浅色/深色共用一套控件。
- 控件：`SettingUi` 构件库提供分组卡片、选项行、开关、下拉、滑条、分段标签、按钮等。
- 下拉/浮层：统一由独立 `WS_POPUP` 窗口承载，支持一体面板与点外关闭。

### 7.3 组件映射

| 界面元素 | 复用组件 |
|---|---|
| 模式切换 | `SettingUi::segmentedPills` |
| 属性分组标题 | `SettingUi::groupLabel` |
| 数值 + 单位输入 | `Ling::TextBox` + 右侧单位 `Ling::Label` |
| 属性滑条 | `Ling::Slider` |
| 预设色板 | `Ling::Button` 色块，点击走系统调色板 |
| 文件格式下拉 | `SettingUi::selectDdl` 或页面内 `SettingUi::Popup` |

| 拼图画布 | `Ling::Canvas`（Direct2D 自绘） |

### 7.4 工具栏沿用

- 现有截图工具栏以槽位数组描述按钮顺序、图标与提示，再逐个创建 `Ling::Button`；该模式可照搬。
- 工具按钮的尺寸、间距、悬停底、选中色、分隔线由 `ToolbarTheme` 统一控制。
- 顶部悬浮胶囊与底部工具栏的外壳沿用 `ToolbarChrome` 的圆角、投影与停悬气泡。
